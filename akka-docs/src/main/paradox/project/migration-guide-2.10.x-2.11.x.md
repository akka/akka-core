# Migration Guide 2.10.x to 2.11.x

## Jackson 2.21

[Akka Serialization Jackson](../serialization-jackson.md) now depends on the Jackson 2.21 long-term-support line. Akka 2.10 used Jackson 2.18 which will not get further updates past January 2027.
